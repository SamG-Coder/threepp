ThreeBrowser

A desktop browser for stock three.js pages. With Native on, injected THREE draws through a threepp GL surface instead of WebGL. three/webgpu is a separate track: Native leaves the stock WebGPURenderer on Chromium Dawn (Vulkan/D3D12) and does not route it through threepp. Toggle Native from the toolbar or press Ctrl+Shift+N.

Native THREE does not run inside iframes, and it does not work on sites that merge three.js with other libraries in one bundle. Open the example HTML itself, not a gallery frame.

How it works

Page JavaScript stays stock three.js. For WebGL pages, ThreeBrowser intercepts three.js / three.module.js, injects a native window.THREE, and packs scene updates into a binary command ring. three_native.dll (C++) runs a threepp OpenGL renderer on a worker thread and presents to an HWND composited behind the WebView. WebGPU pages (three.webgpu.js / three/webgpu) skip that path: WebGPU is a GPU API over Vulkan/D3D12, not a threepp scene graph, so Native re-exports stock WebGPURenderer onto Chromium Dawn and never swaps three.core.js. Toggle Native off to fall back to the page’s own WebGL.

Third-party notice

ThreeBrowser is a Windows host on top of threepp, a C++20 port of the three.js scene graph. The examples above are the official three.js reference pages; they are not bundled here.

  • threepp — C++ scene graph, materials, loaders, and GLRenderer. Copyright © 2021–2026 Lars Ivar Hatledal and threepp contributors. MIT License. API and shaders are a derivative of three.js.
  • three_native — this fork’s C++ command ring (native/three_native.cpp and friends) that maps injected THREE calls onto threepp objects.
  • GLFW — native window and OpenGL context (zlib/libpng).
  • Microsoft Edge WebView2 — the HTML/JS surface. WebGPU pages present through Chromium Dawn (D3D12/Vulkan), not threepp.

Batch LOD · BVH also loads @three.ez/batched-mesh-extensions and three-mesh-bvh from the example page itself. Native THREE does not relicense those packages.

Poseidon is a bundled local demo (MIT) — a Tessendorf FFT ocean using three.js WebGPU / TSL compute. Its src/ is served unchanged; sky panoramas live under /sky/. It is not an official three.js example. Native does not translate its compute FFT into threepp; it runs the stock WebGPURenderer on Dawn.
